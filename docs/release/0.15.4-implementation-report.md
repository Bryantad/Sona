Date: 2026-08-02

## Scope delivered

- tracked VS Code extension rebuild without an AI Console redesign.

## Compatibility decisions

- Python-compatible normal runs preserve their 0.15.3 filesystem/network
  behavior. Safe mode is the restricted boundary.
- Native Core denies filesystem and network access until explicitly granted.
- Native HTTP does not fall back to Python and returns `SONA-HTTP-005`.
- Proof Mode observes Native Core without changing runtime semantics. Program
  diagnostics retain their existing identifiers; `PROOF-*` is reserved only
  for Proof command and receipt infrastructure failures.
- Proof command parsing rejects unknown options, extra positional arguments,
  and malformed engine options with `PROOF-001`; supported engine-selection
  failures retain the existing Native CLI diagnostics.
- Proof receipts are tamper-evident after creation, not signatures,
  attestations, or semantic-parity claims. Receipt verification and trust
  infrastructure remain post-0.15.4 work.
- Seeded random behavior is repeatable per engine; identical sequences across
  engines are not claimed.
- Collection and random are `PARTIAL` in Native Core. HTTP is `UNSUPPORTED`.
- Existing modules, aliases, implicit function-result behavior, cognitive
  runtime behavior, Guardian interfaces, and workspace override precedence are
  preserved.

## Proof Mode bug sweep

A post-implementation adversarial review corrected three Proof-owned defects
without changing ordinary `run`, `exec`, VM, capability, or language behavior:

- strict Proof option parsing now rejects malformed and unknown arguments;
- the observer follows nested workspace-module execution so module output and
  host effects remain in the single ordered receipt evidence stream;
- receipt publication uses atomic create-if-absent semantics on Windows and
  POSIX rather than a replace-capable rename.

Focused tests also lock pre-publication cleanup, post-publication `PROOF-007`
behavior, internal retention of the original program diagnostic when Proof
persistence takes precedence, and fixed SHA-256/HMAC vectors.
