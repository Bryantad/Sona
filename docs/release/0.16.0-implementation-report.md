# Sona 0.16.0 Implementation and Certification Report

**Status:** Windows-local test gates passed; integrated acceptance and
cross-platform certification remain open. Not published.

## Version alignment

The Python package and CLI, Sona interpreter, standard-library manifest,
language server, Rust Native Core workspace, and VS Code extension are aligned
to `0.16.0`. Native Core is still a separately selected executable; Proof Mode
must reject an older executable rather than silently falling back.

## Implemented release scope

- Direct local GGUF model registration, inspection, and inference.
- Durable workflow, event/message, service, state-machine, resource-reporting,
  effect, and capability foundations.
- Sona Guide local-model proposals with deterministic validation, review,
  explicit approval, and one-shot `EDITOR.BUFFER_REPLACE` authorization.
- Proof schema-1 compatibility and the existing Guardian trust boundary.

## Release boundary

- No GitHub branch, tag, or release has been created or updated by this work.
- The local VSIX, wheel, and source distribution were rebuilt from this
  version-aligned source and inspected; they are candidate artifacts, not
  cross-platform-certified release assets.
- Hosted Ubuntu, macOS, and Windows checks require a run against this exact
  candidate source; earlier runs against older commits do not count.
- Native Core compatibility must be demonstrated with the matching `0.16.0`
  executable, not the older `0.15.4` executable found on the user's PATH.
